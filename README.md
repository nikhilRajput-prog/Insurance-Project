🚀 Built & Deployed an End-to-End Vehicle Insurance Prediction System
Excited to share my latest Machine Learning + MLOps project, where I built and deployed a complete Vehicle Insurance Prediction system — from data ingestion and model training to Dockerized cloud deployment and CI/CD.


🔹 Key Features:
• MongoDB Atlas integration for data storage and retrieval
• Modular Data Ingestion & Data Validation pipelines
• Data Transformation & Feature Engineering
• Model Training & Evaluation
• Achieved 91.34% accuracy on the test dataset
• Model storage using AWS S3
• Prediction pipeline using FastAPI
• Web interface for making predictions
• Dockerized application
• Docker image management using Amazon ECR
• Deployment on AWS EC2
• CI/CD pipeline using GitHub Actions
• Self-hosted GitHub Actions runner on EC2


🔹 Tech Stack:
Python | Pandas | NumPy | Scikit-learn | MongoDB Atlas | FastAPI | Docker | AWS S3 | AWS ECR | AWS EC2 | GitHub Actions | MLOps


🔹 Deployment Architecture:
GitHub → GitHub Actions → Docker Build → Amazon ECR → EC2 → Docker Container → FastAPI → MongoDB Atlas
One of my biggest takeaways from this project was understanding that building an ML model is only one part of the ML lifecycle.
The real challenge is taking that model into production with a system that is reproducible, maintainable, and deployable.

Through this project, I gained hands-on experience with the complete ML lifecycle:

Data → Validation → Transformation → Training → Evaluation → Model Storage → Prediction → Docker → CI/CD → Cloud Deployment

I also implemented a training route that allows the ML training pipeline to be triggered through the deployed application.

This project helped me strengthen my practical understanding of Machine Learning, MLOps, AWS, Docker, FastAPI, and CI/CD.

📌 Test Accuracy: 91.34%
